WINDOWS · LOCAL PDF

문서는 크게.
작업은 간편하게.

유니크 PDF Reader로 PDF를 읽고, 필요한 내용을 고치고, 양식을 채우세요. 문서 처리는 내 컴퓨터에서 이루어지며 PDF를 서버에 업로드하지 않습니다.

버전 1.9.1 · Windows 10/11 64비트 · 2026.10.29

Windows 설치 파일 다운로드 · 172 MiB포터블 다운로드 · 176 MiB

설치부터 사용까지 안내 → · 소스 코드·파일 검증

읽기부터 저장까지, 한 곳에서

  • 편안한 읽기: 너비 맞춤, 확대·축소, 검색, 목차와 개인 책갈피. 페이지 사이 간격과 경계선으로 구분합니다.
  • 편집과 주석: 본문 한 줄 교체, 텍스트·메모·형광펜, 페이지 회전·삭제·이동을 지원합니다.
  • 양식 입력: 입력란, 체크박스, 선택 항목을 채우고 PDF 사본으로 저장합니다. 지원되는 XFA 양식과 계산도 사용할 수 있습니다.
  • 빠른 열기: 문서 열기 버튼, 끌어놓기 또는 기본 앱 연결 후 PDF 더블클릭으로 열 수 있습니다.
다운로드 전에 확인하세요

현재 배포 파일은 코드 서명되지 않아 Windows가 게시자를 확인할 수 없다는 경고를 표시할 수 있습니다. 이 페이지의 공식 다운로드와 아래 SHA-256을 확인하세요. macOS·모바일용 앱은 제공하지 않습니다.

OCR, 전자서명 생성, 모든 XFA/Adobe 스크립트와의 완전한 호환은 지원하지 않습니다. 중요한 문서는 사본을 저장한 뒤 결과를 확인하세요.
