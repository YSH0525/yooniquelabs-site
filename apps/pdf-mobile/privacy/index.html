유니크 PDF 개인정보처리방침

Android 앱 · kr.yooniquelabs.pdfsimple
운영자: 유니크랩스(Yoonique Labs)
시행일: 2026년 10월 30일

수집·전송하는 정보

유니크 PDF는 개인정보를 수집하거나 외부 서버로 전송하지 않습니다. 회원 가입, 광고, 분석 SDK, 위치 추적 기능이 없으며 앱에 인터넷 권한을 요청하지 않습니다.

문서 접근과 기기 내 처리

사용자가 Android 파일 선택기에서 선택하거나 다른 앱에서 열기·공유한 PDF와 그 파일 이름만 기기 안에서 처리합니다. 저장소 전체를 탐색하는 권한을 요청하지 않습니다. 원본 PDF를 수정하지 않습니다. 사용자가 파일 선택기에서 클라우드 저장소를 선택하면 해당 제공자의 다운로드 및 개인정보 정책이 적용됩니다.

보관·삭제

문서 표시를 위한 임시 사본은 앱 전용 캐시에 보관됩니다. 정상적인 문서 종료나 교체 시 삭제를 시도하며, 강제 종료 등으로 남은 캐시는 Android 설정 → 앱 → 유니크 PDF → 저장공간 → 캐시 삭제 또는 앱 제거로 삭제할 수 있습니다. 원본 파일은 삭제하지 않습니다.

제3자 제공 및 아동

앱은 개인정보를 수집하지 않으므로 제3자에게 제공하거나 판매하지 않으며 아동의 개인정보도 수집하지 않습니다.

문의

사용자가 이메일로 문의한 경우 답변에 필요한 이메일 주소와 문의 내용은 문의 처리 목적으로만 사용합니다. 문의 시 민감한 PDF를 보내지 마세요. 삭제 요청은 hello@yooniquelabs.kr로 연락해 주세요.

변경 안내

처리 방식이 바뀌면 이 페이지의 시행일과 내용을 수정해 안내합니다. 이 방침은 Windows용 PDF Reader가 아닌 유니크 PDF Android 앱에 적용됩니다.
