필요한 계산까지.

유니크 엑셀은 Excel 형식의 문서를 열고 편집하는 스프레드시트 앱입니다. 셀 입력과 서식부터 수식, 차트와 피벗 테이블까지 익숙한 리본 메뉴로 작업하세요.

버전 1.0.0 · Windows 10/11 64비트 · 설치 파일 제작일 2026.10.23

Windows 설치 파일 다운로드 · 118 MiB설치·사용 방법 →

표를 만들고, 데이터를 정리하세요

  • 파일 열기와 저장: XLSX, XLSM, CSV를 열고 저장합니다. 파일을 끌어놓거나 Ctrl+O로 선택하세요.
  • 입력과 서식: 한글 입력, 셀 병합, 숫자·날짜·통화 서식, 조건부 서식, 복사·붙여넣기와 채우기를 지원합니다.
  • 수식 계산: SUM, IF, VLOOKUP, XLOOKUP 등 수식과 시트 간 참조를 사용합니다.
  • 데이터 분석: 정렬·필터, 표, 차트, 피벗 테이블과 슬라이서를 제공합니다.
  • 인쇄와 검토: 인쇄 미리 보기, 용지·여백·배율 설정, 메모와 댓글을 사용합니다.
사용 전 확인하세요

Microsoft Excel의 모든 기능을 지원하는 것은 아닙니다. Power Pivot 데이터 모델, VBA UserForm, 3차원 차트 등은 지원하지 않으며, 지원하지 않는 내용은 열거나 저장하는 과정에서 빠질 수 있습니다. 중요한 파일은 F12 → 다른 이름으로 저장해 사본으로 작업하세요.

현재 설치 파일은 코드 서명되지 않아 Windows에서 게시자를 확인할 수 없다는 경고가 나올 수 있습니다. 공식 다운로드 주소와 파일 해시를 확인하고 실행 여부를 결정하세요.

배포 파일 확인

설치형 Windows 앱을 제공합니다. 설치 후 별도의 Node.js 또는 Microsoft Excel 설치 없이 실행할 수 있습니다.
