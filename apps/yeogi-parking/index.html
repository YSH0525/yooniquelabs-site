자동차 · 주차 기록

여기주차 - 주차 위치 저장·주차 메모

주차장 층수와 구역, 기둥 번호를 음성메모와 사진으로 저장하는 주차 위치 기록 앱입니다. 지하주차장에서도 직접 남긴 기록을 보고 차를 찾는 데 도움을 줍니다.

말로 남기는 주차 메모

층수·구역·기둥 번호를 말하면 한글 메모로 남길 수 있습니다.

사진으로 주변 모습 기록

주차 위치 주변을 촬영해 보관하고 필요할 때 원본 사진으로 크게 확인합니다.

최근 위치와 히스토리

홈 화면과 위젯에서 최근 기록을 확인하고 이전 주차 기록을 정리합니다.

차량별 기록

여러 차량을 등록하고 차량 블루투스 연결 상태를 확인할 수 있습니다.

이렇게 시작하세요

  1. 차를 세운 뒤 층수와 구역을 말하거나 주변 사진을 찍습니다.
  2. 필요하면 등록한 차량을 구분해 기록합니다.
  3. 돌아올 때 홈 화면·위젯·히스토리에서 메모와 사진을 확인합니다.

자주 묻는 질문

주변 주차장을 찾아주는 앱인가요?

여기주차는 사용자가 주차한 위치를 기록하는 앱입니다. 주변 주차장 검색이나 주차요금 비교를 제공하는 앱으로 안내하지 않습니다.

GPS로 차량을 자동 추적하나요?

자동 위치 추적 대신 직접 남긴 음성메모와 사진을 중심으로 위치를 기억하도록 돕습니다.

메모·사진·차량 블루투스 정보는 앱 자체 서버로 전송하지 않고 휴대폰에 보관합니다. 음성 인식은 기기에 설정된 Android 음성 인식 서비스가 처리할 수 있습니다.
