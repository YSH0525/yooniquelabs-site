설치 · 열기·저장 · 입력·수식 · 분석·인쇄 · 주의사항·문제 해결

1. 설치하고 문서와 연결하기

  1. 다운로드 페이지에서 UniqueExcel-Setup-1.0.0.exe를 내려받습니다. Windows 10/11 64비트용입니다.
  2. 설치 파일을 실행하고 설치 위치를 선택합니다. 현재 사용자용으로 설치되며 바탕화면과 시작 메뉴에 유니크 엑셀 바로가기가 생성됩니다.
  3. 바로가기로 앱을 실행하세요. 별도의 Node.js나 Microsoft Excel 설치는 필요하지 않습니다.
  4. XLSX·XLSM·CSV 파일을 오른쪽 클릭 → 연결 프로그램에서 유니크 엑셀을 선택합니다. 항상 사용하려면 다른 앱 선택 → 항상으로 지정하세요. 목록에 없다면 설치 폴더의 UniqueExcel.exe를 선택합니다.

설치만으로 기존 기본 앱을 바꾸지는 않습니다. 제거할 때는 Windows 설정 → 앱 → 유니크 엑셀 → 제거를 이용하세요.

설치 파일이 코드 서명되지 않아 Windows 경고가 표시될 수 있습니다. 공식 다운로드와 해시를 확인한 뒤 실행 여부를 결정하세요. 보안 프로그램을 끌 필요는 없습니다.

2. 파일 열기와 저장

  • 열기: 파일 → 열기 또는 Ctrl+O를 누르거나 XLSX·XLSM·CSV를 앱으로 끌어놓습니다.
  • 저장: Ctrl+S. 저장 경로가 없는 새 문서는 위치를 묻고, 열린 문서나 이미 저장한 문서는 같은 경로에 덮어씁니다.
  • 사본 저장: F12로 다른 이름·위치를 선택합니다. 원본을 유지하려면 편집 전에 사본부터 만드세요.
  • 형식: 일반 문서는 XLSX, 매크로가 있는 문서는 XLSM으로 저장합니다. CSV 내보내기는 데이터 탭을 이용하세요. CSV는 셀 서식이나 여러 시트를 보존하는 형식이 아닙니다.

작업 내용의 로컬 자동 저장은 파일 저장을 대신하지 않습니다. 특히 10만 칸을 넘는 통합 문서는 자동 저장되지 않으므로 Ctrl+S로 직접 저장하세요. 브라우저 버전은 파일 다운로드 방식이며 Windows 설치형과 저장 동작이 다릅니다.

3. 셀 입력과 간단한 계산

  1. A1에 품목, B1에 수량, C1에 단가, D1에 금액을 입력합니다.
  2. A2에는 노트, B2에는 3, C2에는 2000을 입력합니다. Tab으로 오른쪽 셀로 이동할 수 있습니다.
  3. D2에 =B2*C2를 입력하고 Enter를 누르면 6000이 계산됩니다.
  4. 여러 행을 작성했다면 합계를 표시할 셀에 =SUM(D2:D10)을 입력합니다.
  5. 홈 탭에서 숫자 서식, 글꼴, 색, 테두리와 맞춤을 지정하고 Ctrl+S로 저장합니다.

셀을 다시 편집할 때는 F2, 셀 안 줄 바꿈은 Alt+Enter, 실행 취소는 Ctrl+Z입니다. 수식 입력 중 F4로 절대 참조($)를 전환할 수 있습니다. 아래 시트 탭에서는 시트를 추가하거나 이름을 바꿉니다.

4. 정렬·필터·차트와 피벗

  • 표: 데이터 범위를 선택하고 Ctrl+T 또는 삽입 → 표를 이용합니다.
  • 정렬·필터: 데이터 탭에서 설정합니다. Ctrl+Shift+L로 자동 필터를 켜고 머리글의 필터 버튼에서 값을 선택합니다.
  • 차트: 제목과 값이 있는 범위를 선택하고 삽입 탭에서 차트 종류를 선택합니다.
  • 피벗 테이블: 삽입 → 피벗 테이블에서 생성한 뒤 필드 패널의 행·열·값 영역에 항목을 배치합니다. 원본을 바꿨다면 새로 고침을 사용하세요.
  • 찾기·바꾸기: Ctrl+F / Ctrl+H를 사용합니다.

5. 인쇄하기

파일 → 인쇄 또는 Ctrl+P에서 미리 보기를 확인합니다. 페이지 레이아웃 탭에서 용지 방향, 여백, 인쇄 영역과 배율을 맞춘 뒤 출력하세요.

알아 두면 좋은 점

Excel에서 쓰던 파일이 완전히 똑같이 보이나요?

지원되는 기능 범위에서 파일을 읽고 저장합니다. Power Pivot 데이터 모델, VBA 사용자 폼(UserForm), 3차원 차트 등은 지원하지 않습니다. 열기 안내를 확인하고 F12로 사본을 저장한 뒤 수식·서식·개체를 검토하세요.

매크로를 사용할 수 있나요?

XLSM의 매크로를 보존하며 VBA의 일부 문법을 지원합니다. 매크로는 꺼진 상태로 열리고 신뢰하는 파일에서만 콘텐츠 사용을 선택하세요. 모든 VBA가 동작하는 것은 아니며 외부 프로그램·파일을 실행하는 명령은 제한됩니다.

공동 편집도 되나요?

검토 → 실시간 공동 편집에서 제공합니다. 다른 기기와의 공동 편집에는 별도 중계 서버 설정이 필요하며, 앱 설치만으로 공용 클라우드 공동 편집이 활성화되지는 않습니다.

저장할 수 없다는 메시지가 나와요.

같은 파일을 Microsoft Excel 등 다른 프로그램에서 열고 있다면 닫고 다시 시도하세요. 쓰기 가능한 폴더에 F12로 다른 이름으로 저장하는 방법도 있습니다.
