교대한눈 사용 가이드

교대근무표를 달력에 한 번에 입력하는 방법

주간·야간·휴무가 반복되는 근무표는 날짜를 하나씩 입력하기보다 반복 순서를 먼저 정리하면 관리하기 편합니다. 교대한눈에서 근무 유형과 패턴을 정리하고 변경된 날짜를 확인하는 흐름을 안내합니다.

작성: 유니크랩스 · 2026년 9월 20일 · 개발사 공식 안내

1. 근무 유형부터 맞추기

회사에서 쓰는 근무 명칭과 시간을 먼저 확인하세요. 데이·이브닝·나이트·휴무처럼 구분해 두면 달력을 읽기 쉽습니다. 스토어 화면에 보이는 기본 시간은 예시이므로 실제 출퇴근 시간과 일치하는지 확인하고 자신의 근무에 맞게 설정하세요.

2. 반복 순서와 시작일 확인하기

예를 들어 주간 → 주간 → 야간 → 야간 → 휴무 → 휴무가 반복된다면 이 여섯 칸이 한 주기가 됩니다. 패턴을 적용할 첫날이 주간 첫째 날인지 둘째 날인지에 따라 이후 일정이 달라지므로, 기존 근무표와 시작일을 대조한 뒤 원하는 기간에 적용하세요. 이 순서는 설명용 예시이며 회사별 근무 형태는 다릅니다.

3. 예외 날짜를 따로 확인하기

패턴을 적용한 뒤에는 근무 교환이나 휴가처럼 달라진 날짜를 확인하세요. 여러 날짜에 같은 근무를 넣을 때는 일괄 입력 기능을 활용할 수 있습니다. 먼저 한 주기만 원본 근무표와 비교하면 시작일을 잘못 맞춘 경우를 빠르게 찾을 수 있습니다.

4. 알림과 공유 전에 점검하기

오늘 근무와 다음 근무가 맞는지 확인하고 전날 또는 시작 전 알림을 설정합니다. 근무표 이미지를 가족이나 동료에게 공유하기 전에는 해당 월과 변경된 날짜를 다시 확인하세요. 알림을 쓰려면 휴대폰에서 앱 알림이 허용되어 있어야 합니다.

마지막 확인

  • 근무 이름과 시작·종료 시간이 실제 근무표와 같은가요?
  • 반복 패턴의 기준일을 맞췄나요?
  • 근무 교환 등 예외 날짜를 반영했나요?
