GET STARTED · 1.9.1

설치부터 PDF 저장까지

다운로드 페이지로 이동 →

설치 · 문서 열기 · 읽기 · 편집·주석 · 양식 · 문제 해결

1. 설치하고 기본 앱으로 연결하기

  1. 다운로드 페이지에서 Windows 설치 파일을 받습니다. Windows 10/11 64비트용입니다.
  2. Unique-PDF-Reader-Setup-1.9.1.exe를 실행하고 설치 위치를 선택해 설치를 완료합니다. 바탕화면이나 시작 메뉴의 유니크 PDF Reader로 실행하세요.
  3. PDF 파일을 오른쪽 클릭 → 연결 프로그램 → 다른 앱 선택에서 Unique PDF Reader를 선택하고 항상을 선택합니다. 목록에 없다면 다른 앱 찾기에서 설치 폴더의 Unique PDF Reader.exe를 지정하세요. Windows 버전에 따라 항목 이름이 다를 수 있습니다.
  4. 이후 PDF를 더블클릭하면 해당 문서가 바로 열립니다. 앱이 이미 실행 중이면 기존 창에서 열립니다.

설치를 원하지 않으면 포터블 파일을 실행하세요. 별도 Python 설치는 필요하지 않습니다. 업데이트할 때는 작업한 문서를 저장하고 앱을 종료한 후 새 설치 파일을 실행하세요.

코드 서명이 없어 게시자 확인 경고가 나타날 수 있습니다. 공식 배포 주소와 파일 해시를 확인하고 실행 여부를 결정하세요. 보안 프로그램을 끄지 마세요.

2. 문서 열기

왼쪽의 + 문서 열기 또는 Ctrl+O를 누르면 Windows 파일 선택 창이 열립니다. 폴더에서 PDF를 골라 여세요. 탐색기에서 PDF를 앱으로 끌어놓아도 됩니다. + 버튼은 빈 PDF 생성이 아니라 기존 문서 열기 버튼입니다.

암호가 있는 PDF는 암호를 입력합니다. 입력 파일 크기는 최대 300MB입니다. 처음에는 홈의 샘플 PDF로 기능을 익혀보세요.

3. 크게 읽고 빠르게 찾기

  • 왼쪽 아래에서 페이지 번호를 입력하거나 이전·다음 화살표로 이동합니다.
  • 확대 메뉴의 너비 맞춤 또는 페이지 맞춤을 선택합니다. 왼쪽 아래 접기 화살표를 누르면 메뉴가 접혀 문서가 더 넓어집니다.
  • Ctrl+F로 본문을 검색합니다. Enter는 다음 결과, Shift+Enter는 이전 결과입니다. 이미지로만 된 스캔 PDF는 OCR이 없으므로 검색할 수 없습니다.
  • 목차와 책갈피로 자주 보는 위치에 이동합니다. 개인 책갈피와 최근 문서 위치는 이 컴퓨터에 저장되며 PDF 파일에 삽입되지 않습니다.

4. 편집·주석 후 사본 저장하기

  1. 편집 · 주석을 열고 본문 목록에서 한 줄을 선택해 교체하거나 형광펜을 적용합니다.
  2. 텍스트나 메모 내용을 입력하고 배치 버튼을 누른 뒤 PDF 위의 원하는 위치를 클릭합니다. 기존 메모는 주석 목록에서 수정·삭제합니다.
  3. 필요하면 페이지를 회전·삭제·이동합니다. 잘못 수정했다면 되돌리기를 사용하세요.
  4. 사본 저장으로 다른 파일명에 저장한 다음 다시 열어 결과를 확인합니다. 원본 경로에는 덮어쓰지 않습니다.

본문 교체는 원래 글꼴·자동 문단 배치를 그대로 보존하지 않습니다. 서명된 문서와 편집 제한 문서는 수정이 제한될 수 있습니다. Ctrl+P로 인쇄할 수 있으며 페이지를 이미지로 출력합니다.

5. 양식 입력·자동 계산·저장하기

  1. 입력 가능한 PDF를 열고 양식 입력을 누릅니다.
  2. 현재 페이지의 입력란, 체크박스, 라디오 버튼과 선택 목록을 채웁니다.
  3. 입력 적용으로 문서에 반영합니다. 지원되는 계산은 적용 또는 저장할 때 갱신됩니다.
  4. 반복 행이 있는 지원 양식에서는 입력을 먼저 적용한 뒤 행을 추가·삭제합니다.
  5. 양식 PDF 저장으로 사본을 저장하고, 저장한 PDF를 다시 열어 입력값과 계산 결과를 확인합니다.

홈의 양식 샘플과 XFA 계산 샘플로 연습할 수 있습니다. XFA와 스크립트는 지원되는 문법·구조 범위에서 동작합니다. 지원하지 않는 계산 안내가 나오면 결과를 완전하다고 간주하지 말고 원래 양식 제작자가 권장하는 앱에서 확인하세요.

자주 묻는 질문

더블클릭했는데 다른 앱이 열려요.

Windows 설정 → 앱 → 기본 앱에서 .pdf의 기본 앱을 유니크 PDF Reader로 선택하세요.

PDF 안의 여백도 없앨 수 있나요?

앱의 불필요한 상하 여백은 줄였지만 PDF 원본 안의 흰 여백은 문서의 일부입니다. 너비 맞춤이나 확대를 이용하세요.

저장한 내용이 보이지 않아요.

입력 적용 후 저장했는지, 원본이 아니라 방금 저장한 사본을 열었는지 확인하세요. 지원하지 않는 양식·스크립트는 안내 메시지를 확인하세요.
