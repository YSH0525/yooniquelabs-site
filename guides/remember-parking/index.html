여기주차 사용 가이드

지하주차장 층수·기둥 번호를 사진과 음성으로 기억하기

주차한 건물은 기억나는데 지하 몇 층인지, 어느 기둥 옆인지 헷갈리는 경우가 있습니다. 여기주차는 직접 남긴 음성메모와 사진을 통해 주차 위치를 다시 확인하는 앱입니다.

작성: 유니크랩스 · 2026년 9월 20일 · 개발사 공식 안내

1. 차를 세운 직후 세 가지 기록하기

차에서 내린 뒤 안전한 곳에서 층수, 구역, 기둥 번호를 남기세요. 예를 들어 ‘지하 3층, C구역, 17번 기둥 옆’처럼 순서를 정하면 나중에 읽기 쉽습니다. ‘엘리베이터 근처’처럼 여러 장소에 해당하는 표현보다 표지판에 적힌 번호가 도움이 됩니다.

2. 음성메모와 사진 나눠 활용하기

홈 화면의 음성메모로 위치를 말해 한글 메모로 남기거나 사진찍기로 주변 표지판을 기록합니다. 음성 인식이 끝나면 층수와 숫자가 맞게 남았는지 확인하세요. 사진에는 차량만 크게 담기보다 구역 표지와 기둥 번호가 함께 보이도록 촬영하는 편이 좋습니다.

3. 돌아올 때 최근 기록부터 확인하기

홈 화면이나 위젯에서 최근 주차 위치를 확인하고, 필요하면 히스토리에서 이전 기록을 찾습니다. 여러 차량을 등록해 사용하는 경우에는 현재 찾는 차의 기록인지도 확인하세요. 사진이 작게 보이면 원본 보기로 표지판을 확인할 수 있습니다.

4. 기능 범위 알아두기

여기주차는 주변 주차장을 검색하거나 GPS로 차량을 자동 추적하는 앱이 아닙니다. 사용자가 남긴 메모와 사진이 위치 확인의 기준입니다. 차량 블루투스 연결 상태 확인 기능도 제공하지만, 층수와 구역 정보는 직접 남겨두는 것이 좋습니다.

마지막 확인

  • 층수와 구역·기둥 번호가 들어 있나요?
  • 음성 인식된 숫자가 맞나요?
  • 최근 기록이 현재 주차한 차량의 기록인가요?
